## Silent Fox Delta

The intended library/importer beta includes Characters, Vehicles, Weapons and
Camo. The catalog is designed for browsing thumbnails and metadata; model
imports read from the user's own local game installation on demand.

Planned beta features include drag-and-drop import, sequential imports of
selected assets, cancellation, Camo image export as PNG/TGA, and update controls
inside the add-on's Blender preferences. Unknown asset names stay visible under
their internal names. Related parts are limited to verified relationships.

Blender materials approximate the game's materials. A game-ready model or
material exporter, complete assembly coverage and all-grade weapon replacement
are not included in this library/importer beta.

## Installation and Updates

After a reviewed release becomes available, install the appropriate add-on ZIP.
Each Silent Fox product uses its own game executable and cache folder. Do not
put caches inside the game installation.

Delta is designed to offer **Check for Updates** and **Install Update** in its
own Blender preferences. Automatic checking is optional; installing an update
requires a click. Save your work and restart Blender after installation.

Versioned releases and independent update channels will be added only after
their exact packages are reviewed and tested. No current private test build is
advertised as a public release. Other products' updater availability will be
documented with their own releases rather than assumed from Delta's behavior.
