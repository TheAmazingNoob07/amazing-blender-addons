# Feedback

Use the bug report form and select the affected add-on. Include:

- Add-on name and version.
- Blender version and operating system.
- Steps to reproduce the problem.
- Expected behavior and actual result.
- Exact asset tile/category or texture preset, when relevant.

A cropped screenshot or short error excerpt can help. Remove personal paths,
account details and other identifying information first. Do not attach native
game assets, extracted caches, complete Blender scenes, music files, passwords
or access tokens.

For Silent Fox, specify whether the problem involves setup, catalog loading,
dragging/importing, materials, verified related parts, batch imports,
cancellation/undo, Camo export or updates. The Delta library/importer beta does
not include a game-ready model/material exporter.

For Amazing Packer, include the selected preset, output format and naming
settings. Describe texture inputs without uploading copyrighted game textures.

Public downloads are not available yet. A private-test report should identify
the exact version tested and should not attach the private installation ZIP.

Community feedback does not imply a promised response time. No automatic
scene, game-file, texture or diagnostic upload is part of the documented workflow.
